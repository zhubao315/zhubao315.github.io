## 直接答案

选一部闲置手机，安装拙诚日课的全离线 APK 并让它常亮：默认停在每日金句，内容全部在手机内运行，不联网、不注册、不需要 API Key。六个栏目（金句、AI 伴读、日课、微习惯、静坐、档案）由你手动左右切换，不会被自动轮播打断。

## 为什么是"终端"而不是又一个 App

修习类应用常依赖账号、推送与网络，反而把注意力带走。拙诚日课把方向反过来：让设备成为一张安静的桌面，打开就停留在当下这一句。

硬件原型是红米 Note 2（MT6795，刷入 LineageOS 16）。APK 基座来自 PhoneBox，离线版只借它承载 WebView；内容本身不依赖云端。

## 实际怎么做

1. **准备设备**：一部可运行 WebView 的旧手机；原型机使用 LineageOS 16，同时提供横竖屏、平板与桌面预设。
2. **获取安装包**：从项目落地页下载全离线 APK（页面给出字节数与 SHA-256，可先校验）。
3. **安装并常亮**：打开后默认进入全屏金句，无顶部标题栏和底部导航。
4. **切换栏目**：滑动、点击左右半区、点栏目名或按方向键；长按进入配置，不自动轮播。
5. **按需配置**：设备预设与自定义可调整留白、字号、默认栏目和显示栏目。

配置示例（字段以仓库当前实现为准）：

```json
{
  "preset": "redmi-note2-portrait",
  "default_column": "quotes",
  "auto_rotate": false,
  "columns": ["quotes", "companion", "daily", "microhabits", "meditation", "archive"]
}
```

## 实测结果

2026-11-27 在仓库本地执行 `pytest -q`，结果 **22 passed**。落地页、离线演示与 APK 下载地址在 2026-11-26 实测均返回 HTTP 200。项目提供 999 条金句（43 个来源）、999 条 AI 伴读条目与 30 条标注真实时长的微习惯。

## 边界

- AI 伴读是预置的自包含条目，不会在线生成新的个性化内容。
- 兼容性以仓库说明为准；不要把原型机配置当成所有设备的保证。
- 代码为 MIT，数据许可另行说明；APK 的完整性请自行校验 SHA-256。

## 常见问题

**会被推送或轮播打断吗？**
不会。默认停在金句，六个栏目手动切换，不自动轮播。

**桥接版和离线版怎么选？**
离线版 2.1 是默认形态，不需要电脑、网络或 API Key；桥接版 v1.4.4 保留电脑端中枢与硬件采集，适合需要集中管理的用户。
