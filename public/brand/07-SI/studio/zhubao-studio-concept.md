# ZHUBAO Digital Studio / AI Lab · 空间概念规范（SI-01）

> 定位：Personal Digital Studio & AI Research Lab · 主题 Midnight Signal
> 本文件是空间设计任务书：实物/效果图需由空间设计师或后续图像生成执行，不得虚构已建成事实。

## 1. 空间基调

深空蓝黑（#07111F）墙体 + 深海军蓝（#0B1D33）家具面板 + 电光蓝（#2563EB）线性光 + 四方向节点色仅作为内容标识。
语言：现代建筑 · 极简工业 · 模块化 · 理性秩序。**不是电竞房、不是赛博朋克、不用满屋 RGB 灯带。**

## 2. 功能模块

| 模块 | 内容 | 品牌植入 |
| --- | --- | --- |
| Logo 墙（视觉中心） | Z-Grid 亚克力/金属立体字，暖白背光轮廓 | 母版 1:8 放大，四周留白 ≥ 1u×比例 |
| AI 研究工作区 | 双 27" 显示器升降桌 ×2 工位 | 屏保=Hero Background 资产 |
| 数据展示屏 | 43" 竖屏常驻 QL Dashboard | 直接复用 `06-PRODUCTS/quantified-life` 资产 |
| 作品墙 | 六个子项目装裱卡（Banner 同构版式） | 每卡右下 A ZHUBAO PROJECT 徽章 |
| 会议/演示角 | 98" 显示屏 + 白板 | 默认背景=视频通话背景资产 |
| 灯光 | 3000K 基础照明 + 4000K 工作光 + 电光蓝暗藏灯带 ≤ 15% 面积 | 灯带色 #2563EB 低饱和 |

## 3. 材质清单

哑光深灰矿绵板 / 深色橡木饰面 / 阳极氧化铝型材 / 磨砂亚克力（激光雕刻 Logo）/ 防静电深灰地材。禁止：镜面黑玻璃、炫彩板、皮革拉扣。
