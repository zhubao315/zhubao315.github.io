# ZHUBAO 品牌定位 · Brand Positioning

> v1.0 · 2026-11

## 定位陈述 Positioning Statement

**对于**关注 AI 工程、知识方法与量化生活的实践者，
**ZHUBAO** 是一个公开运行的个人数字品牌，
**因为它**把系统、知识、数据与作品纳入同一套可检验的操作系统，
**不同于**只输出观点或包装人设的内容型个人品牌，
**ZHUBAO 的一切主张都有代码、文档与数据支撑。**

## 定位坐标

| 维度 | 位置 | 说明 |
| --- | --- | --- |
| 内容型 ↔ 实践型 | 实践型 | 作品与系统优先于观点 |
| 热点型 ↔ 长期型 | 长期型 | 资产按十年标准维护 |
| 单点专家 ↔ 复合系统 | 复合系统 | 四方向构成闭环 |
| 人设包装 ↔ 过程公开 | 过程公开 | 包括失败与被修正的判断 |
| 消费向 ↔ 专业向 | 专业向 | 面向同行与实践者写作 |

## 竞争/参照框架

个人品牌常见形态与 ZHUBAO 的差异：

| 类型 | 典型形态 | ZHUBAO 的不同 |
| --- | --- | --- |
| 内容型 IP | 流量驱动，内容即产品 | 内容是系统的说明书，不是本体 |
| 咨询/课程型 | 以售卖转化为核心 | 不设转化 KPI，先保证真实 |
| 作品合集型 | 静态作品集 | 资产持续演进，有版本与状态 |
| 生活方式型 | 审美先行 | 数据与工程先行，审美克制 |

## 场景化定位口径

| 场景 | 一句话口径 |
| --- | --- |
| GitHub / 技术社区 | AI 工程与系统实践者的公开工作区 |

| 演讲 | 「构建—思考—测量—创造」闭环的实践样本 |
| 社交 | 一个长期主义工程师的数字分身 |

## 定位禁区

- 不声称未发生的成绩、头衔、合作关系、出版状态。
- 不与任何真实公司/品牌作对比性贬低。
- 不把「个人品牌」本身当成产品卖给他人。
